# SpendWise

## Project Description
SpendWise is a responsive web application designed to help users track, manage, and visualize their daily personal expenses. It features a clean user interface, transaction categorization, and persistent local storage to empower users to stay on top of their financial goals.

## Technologies Used
* **HTML5** for structural markup
* **CSS3 / Flexbox / Grid** for responsive styling and layout
* **JavaScript (ES6+)** for application logic, state management, and DOM manipulation
* **Git & GitHub** for version control
* **Netlify** for continuous deployment and web hosting

## Deployment Process Summary
1. Organized project files into a clean root structure with `index.html` as the entry point.
2. Initialized a local Git repository, committed the files, and pushed them to a public GitHub repository.
3. Connected the GitHub repository to Netlify via the web dashboard for automated continuous deployment.
4. Customized the Netlify subdomain to create a clean, memorable project URL.
5. Performed a CI/CD test by pushing a code update to GitHub and verifying automatic deployment on Netlify.

## Challenges Encountered During Deployment
* **Asset Pathing:** Initially encountered broken styling links because absolute paths were used instead of relative paths. This was resolved by updating all asset references to relative directories (`css/style.css`).

## Lessons Learned
* Learned how to seamlessly bridge version control on GitHub with modern cloud hosting platforms like Netlify.
* Gained a deep understanding of continuous deployment workflows and how automated triggers streamline the release of web updates.
